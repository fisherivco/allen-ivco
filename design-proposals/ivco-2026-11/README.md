# Design proposals — ivco.ai, 2026-11

Two design directions proposed under issue #4 (T3), merged via PR #5. Both are kept in the repo so they can be reviewed again later.

- `a/` — **research press**: IVCO as a publication; a light editorial theme where the brand line is the masthead and everything else is quiet reading furniture.
- `b/` — **analyst workbench**: IVCO as an instrument; a dark palette where the first screen shows the valuation range and the published TSMC Confidence Coefficient pairs before any copy.

**Owner ruling 2026-11-25 (verbatim, issue #4):** 「B, 並寫入 IVCO 相關文件中，接下來依這個為基礎進行品牌視覺發展，品牌色碼、風格、呈現方式、表達角度都要詳細記錄，同時這兩個範本也要保留下來在 repo 中，未來可回頭審視」

Direction **B** is the pick. It is codified as the canonical visual identity in `docs/brand/visual-identity.md` (issue #7). Direction A remains here for later review only; it is not normative.
